Overview

A modern, responsive blogging site where signed-in users manage a profile and publish, edit and delete their own rich-text blog posts.

Key Features

Sign in and create a profile with display name, username and bio

Edit your own profile information

Create blog posts with a title and rich-text content

Edit and delete your own posts, with author and creation/update dates shown

Browse published posts on a card-based home page and read full posts
